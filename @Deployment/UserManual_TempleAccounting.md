# Section 1: บทนำและการติดตั้ง

## 1.1 เกี่ยวกับระบบ

ระบบบัญชีวัดแหลมยาง (Temple Accounting System) เป็นโปรแกรมบัญชีที่พัฒนาขึ้นเฉพาะสำหรับการบริหารจัดการการเงินของวัด รองรับการบันทึกรายรับ รายจ่าย การโอนเงินภายในระหว่างกองทุน การพิมพ์รายงานทางการเงิน และการจัดการเอกสารใบเสร็จอย่างครบวงจร

[รูปภาพที่ 1: หน้าจอหลักโปรแกรม FrmMain — แสดง Sidebar เมนูนำทาง, การ์ดภาพรวม 4 การ์ด, และ Header ด้านบน]

## 1.2 ความต้องการของระบบ

| รายการ | ข้อกำหนด |
|--------|----------|
| ระบบปฏิบัติการ | Windows 10 / Windows 11 (64-bit) |
| หน่วยความจำ (RAM) | ขั้นต่ำ 4 GB |
| พื้นที่จัดเก็บ | อย่างน้อย 200 MB |
| ซอฟต์แวร์เพิ่มเติม | ไม่จำเป็นต้องติดตั้ง — โปรแกรมรวมทุกอย่างในตัว (Self-Contained) |

## 1.3 วิธีการติดตั้ง

1. **แตกไฟล์ ZIP**: ดับเบิ้ลคลิกไฟล์ `TempleAccounting_PerfectPoint_v0.zip` แล้วลากโฟลเดอร์ `Release_PerfectPoint_v0` ออกมาวางที่ Desktop หรือโฟลเดอร์ที่ต้องการ

2. **ตรวจสอบไฟล์**: ภายในโฟลเดอร์จะประกอบด้วย:
   - `TempleAccounting.exe` — ไฟล์รันโปรแกรม (มีไอคอนวัด)
   - โฟลเดอร์ `Database/` — ฐานข้อมูล TempleAccounting.accdb
   - โฟลเดอร์ `Receipts/` — สำหรับเก็บรูปภาพใบเสร็จ (สร้างอัตโนมัติ)
   - ไฟล์ `.dll` ต่างๆ — ไลบรารีที่จำเป็น

3. **เริ่มใช้งาน**: ดับเบิ้ลคลิก `TempleAccounting.exe` เพื่อเริ่มโปรแกรม

[รูปภาพที่ 2: หน้าจอแรกเมื่อเปิดโปรแกรม — แสดง Dashboard พร้อมการ์ดภาพรวม]

> **หมายเหตุ**: โปรแกรมถูกออกแบบให้พกพาได้ (Portable) สามารถคัดลอกทั้งโฟลเดอร์ไปไว้ใน Flash Drive และรันบนเครื่องอื่นได้ทันที โดยไม่ต้องติดตั้งเพิ่มเติม

# Section 2: การใช้งานประจำวันและการบันทึกข้อมูล

## 2.1 การบันทึกรายรับ (Income)

หน้าจอบันทึกรายรับใช้สำหรับบันทึกเงินที่รับเข้าวัด ไม่ว่าจะเป็นเงินบริจาค เงินทอดพระเนตร ดอกเบี้ยเงินฝาก หรือรายได้อื่นๆ

### วิธีเข้าถึง

คลิกปุ่ม **💰 บันทึกรับเงิน** ในเมนูด้านซ้าย

[รูปภาพที่ 3: หน้าจอบันทึกรายรับ FrmIncome — แสดงฟิลด์วันที่, ประเภทรายรับ, กองทุน, บัญชีธนาคาร, ช่องทางรับเงิน, รายละเอียด, จำนวนเงิน, หมายเหตุ]

### ฟิลด์ข้อมูล

| ฟิลด์ | คำอธิบาย |
|-------|----------|
| **วันที่ทำรายการ** | วันที่ที่ได้รับเงิน (ค่าเริ่มต้นเป็นวันที่ปัจจุบัน) |
| **ประเภทรายรับ** | เลือกประเภท เช่น เงินบริจาคทั่วไป, เงินทอดพระเนตร, ดอกเบี้ยเงินฝาก, รายได้อื่นๆ |
| **กองทุน** | เลือกกองทุนที่รับเงิน เช่น กองทุนทั่วไป, กองทุนกฤติยาธรรม |
| **บัญชีธนาคาร (ถ้ามี)** | หากเงินเข้าบัญชีธนาคาร ให้เลือกบัญชีที่เกี่ยวข้อง |
| **ช่องทางรับเงิน** | เลือกช่องทาง: เงินสด, โอนธนาคาร, พร้อมเพย์, e-Donation |
| **เลขอ้างอิง (ถ้ามี)** | แสดงเฉพาะเมื่อเลือก "พร้อมเพย์" หรือ "e-Donation" ใช้กรอกเลขที่อ้างอิงการโอน |
| **รายละเอียดรายการ** | คำอธิบายรายการ เช่น "เงินบริจาคจากคุณสมชาย" |
| **จำนวนเงิน (บาท)** | จำนวนเงินที่ได้รับ (ตัวเลขเท่านั้น) |
| **หมายเหตุ** | ข้อมูลเพิ่มเติม (ไม่บังคับ) |
| **หลักฐาน/ใบเสร็จ** | แนบรูปภาพใบเสร็จ (ดู Section 3) |

### ปุ่มควบคุม

| ปุ่ม | หน้าที่ |
|------|--------|
| **💾 บันทึกรายการ** | บันทึกข้อมูลลงฐานข้อมูล |
| **❌ ล้างข้อมูล** | ล้างข้อมูลทั้งหมดในฟอร์มเพื่อเริ่มกรอกใหม่ |
| **📥 นำเข้า Excel** | นำเข้ารายรับจำนวนมากจากไฟล์ Excel (ดู Section 5) |

### วิธีการบันทึกรายรับ

1. ตรวจสอบ **วันที่ทำรายการ** ว่าถูกต้อง
2. เลือก **ประเภทรายรับ** ที่ตรงกับรายการ
3. เลือก **กองทุน** ที่เกี่ยวข้อง
4. หากเงินเข้าบัญชีธนาคาร ให้เลือก **บัญชีธนาคาร**
5. เลือก **ช่องทางรับเงิน**
6. กรอก **รายละเอียดรายการ**
7. กรอก **จำนวนเงิน** เป็นตัวเลข
8. (ไม่บังคับ) แนบรูปภาพใบเสร็จ (ดู Section 3)
9. กดปุ่ม **💾 บันทึกรายการ** หรือกด **Enter** ที่ช่องสุดท้าย

> **เคล็ดลับ**: ทุกฟิลด์สามารถกด Enter เพื่อเลื่อนไปยังฟิลด์ถัดไป กด Enter ที่ฟิลด์สุดท้ายจะบันทึกทันที

### การแก้ไขรายการเดิม

หากต้องการแก้ไขรายการที่มีอยู่แล้ว:
1. ไปที่หน้า **📖 รายการทางบัญชี**
2. ค้นหารายการที่ต้องการแก้ไข
3. คลิกปุ่ม **✏️ แก้ไข**
4. ฟอร์มจะเปิดในโหมดแก้ไข — แก้ไขข้อมูลตามต้องการ
5. กด **💾 บันทึกการแก้ไข**

### ฟิลด์ข้อมูล

## 2.4 การจัดการประเภทรายการ กองทุน และบัญชีธนาคาร

หน้านี้ใช้สำหรับจัดการข้อมูลหลัก (Master Data) ทั้งหมดของระบบ

### วิธีเข้าถึง

คลิกปุ่ม **⚙️ ตั้งค่าระบบ** ในเมนูด้านซ้าย

[รูปภาพที่ 6: หน้าจอจัดการข้อมูลหลัก FrmMasterData — แสดง 3 แท็บ: ประเภท, กองทุน, บัญชีธนาคาร]

### แท็บ "ประเภทรายการ"

จัดการหมวดหมู่รายรับและรายจ่าย:
- **เพิ่ม**: กรอกชื่อหมวดหมู่ → เลือกชนิด (รายรับ/รายจ่าย) → กด **เพิ่ม**
- **แก้ไข**: คลิกแถวในตาราง → แก้ไขชื่อ → กด **แก้ไข**
- **ลบ**: เลือกแถว → กด **ลบ**

### แท็บ "กองทุน"

จัดการรายชื่อกองทุนของวัด:
- **เพิ่ม**: กรอกชื่อกองทุน → กด **เพิ่ม**
- **ลบ**: เลือกแถว → กด **ลบ**

### แท็บ "บัญชีธนาคาร"

จัดการรายชื่อบัญชีธนาคารที่วัดใช้:
- **เพิ่ม**: กรอกชื่อธนาคาร, เลขบัญชี, ชื่อบัญชี → กด **เพิ่ม**
- **ลบ**: เลือกแถว → กด **ลบ**

### วิธีการส่งออก

1. **ตั้งรหัสเครื่องต้นทาง** (ทำครั้งแรกครั้งเดียว):
   - กรอกรหัสเครื่อง (เช่น `MAIN-PC` หรือ `KUTI-01`)
   - กด **บันทึกรหัส**
2. **เลือกช่วงข้อมูล**:
   - **ส่งออกเฉพาะที่ยังไม่เคยส่ง**: ส่งออกเฉพาะข้อมูลใหม่ตั้งแต่ส่งออกครั้งล่าสุด
   - **กำหนดช่วงวันที่เอง**: เลือกวันที่เริ่ม-สิ้นสุด
   - **ส่งออกทั้งหมด**: ส่งออกทุกข้อมูล
3. กด **📤 ส่งออก** → เลือกปลายทาง (เช่น Flash Drive)
4. โปรแกรมจะสร้างไฟล์ `TransactionData.xlsx` และคัดลอกรูปใบเสร็จที่เกี่ยวข้อง

> **เคล็ดลับ**: ใช้โหมด "ส่งออกเฉพาะที่ยังไม่เคยส่ง" เป็นประจำ เพื่อหลีกเลี่ยงข้อมูลซ้ำ

# Section 6: การสำรองและคืนค่าข้อมูล

การสำรองข้อมูลเป็นสิ่งสำคัญอย่างยิ่งในการป้องกันข้อมูลสูญหาย

## 6.1 การสำรองข้อมูล (Backup)

1. คลิกปุ่ม **💾 สำรองข้อมูล** ในเมนูด้านซ้าย
2. เลือกโฟลเดอร์ปลายทางสำหรับเก็บไฟล์สำรอง
3. ระบบจะสร้างไฟล์ `TempleAccounting_YYYYMMDD_HHmmss.accdb` (ชื่อไฟล์มีวันที่-เวลา)
4. ระบบจะสำรองทั้ง:
   - ฐานข้อมูล (.accdb)
   - โฟลเดอร์รูปภาพใบเสร็จ (Receipts/)
   - ไฟล์นำเข้า (Import/)

[รูปภาพที่ 21: หน้าจอสำรองข้อมูล — แสดง FolderBrowserDialog เลือกโฟลเดอร์ปลายทาง]

## 6.2 การคืนค่าข้อมูล (Restore)

1. คลิกปุ่ม **🔄 คืนค่าข้อมูล** ในเมนูด้านซ้าย
2. เลือกไฟล์สำรองจาก ZIP ไฟล์ที่สำรองไว้
3. ระบบจะแทนที่ฐานข้อมูลปัจจุบันด้วยข้อมูลจากไฟล์สำรอง
4. โปรแกรมจะรีสตาร์ทอัตโนมัติ

> **คำแนะนำ**: ควรสำรองข้อมูลอย่างน้อยสัปดาห์ละครั้ง หรือทุกครั้งหลังบันทึกรายการจำนวนมาก
